# Pentaract Infinite - Alpha V0.05

This is a simple experimental N-dimensional version of Pentaract Placer, featuring an experimental dual-time system, a 3D–6D model maker, a primitive N-dimensional texture maker, and experimental "water" mechanics.

Not everything is finished yet. This is still a very early and highly unfinished version of the project, which began on May 12, 2026 (if my memory serves me correctly).
